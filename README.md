# Священный Баяностан (Bayanostan) 🍏🛞

Официальный веб-портал, посвященный главному пророку и продавцу покрышек на Волгу — Юрию Баянову.

## О проекте
Баяностан — это интерактивное святилище Сумской области, где царит культ яблок с глазами, шиномонтажей и безумных теорий заговора. Сайт создавался как мем-манифест, объединяющий глубокий абсурдный лор и ветхозаветный мрачный дизайн. Откройте в себе сленг разнорабочих, узнайте тайные смыслы известных картин и бросьте покрышку в лицо врагу! 

### Основные Священные Фичи:

- 📜 **Завет Баяна:** 30 сгенерированных глав об исторической судьбе Юрия. 
- 🤖 **Летописи (ИИ):** Динамическая генерация исторических преданий с помощью Gemini API на основе выбранного вами года в агрессивном стиле разнорабочих.
- 🍏 **Обряд Бросания:** Загрузите любую картинку и бросайтесь в нее объемными полупрозрачными яблоками или авто-покрышками со звуковым (визуальным) шлепком.
- ⏳ **Часы Забвения:** Обратный отсчет до 69 лет (момента, когда Баянов нашел свой окончательный приют в лесу). Можно *ускорить* забвение.
- 💰 **Сбор яблочных налогов:** Калькулятор конвертации фиатных валют и человеко-часов в истинную ценность — Сумские яблоки по строгой секретной формуле.
- 🖼 **Святилище Артов:** Прямая трансляция яблочных артов по API Gelbooru.
- 🕯 **Эстетика:** Ветхозаветно-готический дизайн (золото, тьма и стекло), падающие красные яблоки (снежинки) и эмбиент при входе во Врата.

## 🛠 Технологии

Приложение полностью построено с использованием современного стека:
- **Core:** React 18, Vite (SWC)
- **3D / Анимации:** React Three Fiber (`@react-three/fiber`, `@react-three/drei`), Framer Motion, Vanilla CSS / CSS Modules
- **Интеграции:** 
  - *Google Gemini 1.5 Flash* (через REST API) для динамического ЛОРа
  - *Gelbooru API* (через CORS Proxy `allorigins`)

## 🚀 Установка и запуск

Чтобы стать свидетелем Баянова локально:

1. Склонируйте репозиторий:
   \`\`\`bash
   git clone https://github.com/yshxsp/bayan.git
   cd bayan
   \`\`\`

2. Установите зависимости:
   \`\`\`bash
   npm install
   \`\`\`

3. Создайте файл \`.env\` в корне проекта и добавьте священные ключи (без них не будет работать галерея артов и ИИ-генератор):
   \`\`\`env
   VITE_GELBOORU_API_KEY=ваш_ключ_gelbooru
   VITE_GELBOORU_USER_ID=ваш_id_gelbooru
   VITE_GEMINI_API_KEY=ваш_ключ_gemini
   \`\`\`

4. Откройте Врата в локальном сервере!
   \`\`\`bash
   npm run dev
   \`\`\`
   
## Иерархия Папок 
- \`/public\` - Статические ресурсы, аудио сопровождение \`bayan-audio.mp3\`.
- \`/src/components\` - Все функциональные вкладки и интерактивные храмы приложения.
- \`index.css\` - Глобальный мрачный, золотой стиль оформления.
